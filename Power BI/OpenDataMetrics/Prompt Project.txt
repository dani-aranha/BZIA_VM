📊 PROJECT STATUS — Power BI
DBAS2101/3182 – Data Reporting (B)
Halifax Regional Municipality (HRM) – Open Data (ArcGIS Hub)

🎯 Project Objective
Evaluate the real usage and overall health of the HRM public dataset catalog by distinguishing between:

Historical impact
Current activity intensity
Dataset maturity

The goal is to support data governance and strategic decision-making, rather than purely exploratory analysis.

📦 Data Source
ArcGIS Hub – Open Data (HRM)

Dataset: Usage statistics CSV
~639,000 records
Usage tracked over time per dataset

Fixed Reference Date

October 19, 2025 (last real update of the data)

✅ The use of a fixed date is intentional, ensuring analytical stability, reproducibility, and consistent age calculations.

🧱 Data Model — ✅ COMPLETED
Model Type
Star Schema
Tables

Fact_Usage – usage events over time
Dim_Dataset – one row per dataset
Dim_AgeBand – dataset age categories
Dim_Cluster – health / usage classification

Relationships

Artificial key: DatasetKey = Dataset | OD_ID
One‑to‑many: Dim_Dataset → Fact_Usage

✅ Model validated visually and logically.
