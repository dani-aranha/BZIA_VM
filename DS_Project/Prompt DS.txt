📌 Project Prompt — Final (Atualizado e Alinhado ao Curso)
Binary Classification of Obesity Risk Using Behavioral Attributes

🔍 Project Context
This project develops an end‑to‑end applied machine learning workflow using structured health‑related data, with a strong emphasis on problem framing, reproducibility, model validation, and interpretability, aligned with Applied Analytics and Business Intelligence practices.
The dataset used is the UCI – Estimation of Obesity Levels Based on Eating Habits and Physical Condition, which contains demographic and behavioral attributes collected from individuals in Mexico, Peru, and Colombia.
Rather than treating the task as a purely academic classification problem, the project is framed as a risk‑screening and decision‑support application, suitable for prevention programs and analytical reporting contexts.

🎯 Problem Definition
Binary Classification Task — Obesity Risk Screening
The original multi‑class target (NObeyesdad) is reformulated into a binary, decision‑oriented target:

















Binary TargetDefinition0 — No Obesity RiskInsufficient Weight, Normal Weight1 — Obesity RiskOverweight (Levels I & II) + All Obesity Types
This reframing supports:

Preventive health screening
Prioritization of intervention efforts
Behavioral risk profiling
Policy‑oriented analytics


🧠 Key Analytical Decisions (Project Evolution)
⚠️ Leakage Awareness and Feature Redesign
During model optimization, near‑perfect ROC‑AUC values revealed semantic leakage caused by including anthropometric variables (Weight and Height), which directly determine obesity labels via BMI.
✅ Design Adjustment

Weight and Height were explicitly removed
The project scope was realigned to focus on behavioral and lifestyle risk factors, not diagnostic classification


This decision improves generalization, interpretability, and real‑world analytical relevance.


✅ Final Modeling Scope
✅ Included Features

Eating habits and dietary behavior
Physical activity frequency
Lifestyle indicators (technology use, transportation)
Family history
Demographics (non‑diagnostic)

❌ Excluded Features

Weight
Height

This decision is explicitly documented as part of the analytical narrative.

Result

Cross‑validated ROC‑AUC ≈ 0.92
